# Изменения

## 0.1.0 — 2026-10-23

- Начальная функциональная 2D-реализация Avalonia с русским интерфейсом, ReactiveUI/Fody и централизованным DI.
- Реальный автономный OSM-пакет Дрозды — Новинки, SQLite/R-tree, A*, разные профили, измеренная статистика.
- Android startup, сборка APK, отсутствие INTERNET в Release-манифесте.
- Отдельный локальный эксперимент MapLibre с реальным Copernicus DEM; не встроен в приложение.
- xUnit/Headless, тест weaving, GitHub Actions, документация и явные блокеры полной приёмки.
