# Изменения

Невыпущенные изменения находятся в [changes/](changes/README.md). Этот файл обновляется Towncrier при выпуске релиза.

## 0.2.0 — 2026-10-23

- Перестановка координат касанием за ручку, статичные номера и удаление красным ×.
- Исправлено переключение альтернатив на карте и устранены почти совпадающие трассы.
- Запас кабеля по умолчанию 10%, удалены раздел данных и подзаголовок.
- Отдельный Persistence, uv/pyproject.toml/uv.lock, форматирование C#/XAML и пояснение радиуса Земли.
- Потоковая подготовка полного OSM Беларуси, уровни детализации, фоновая распаковка, выпуск автономных APK и Windows setup.
- Дополнительные touch/UI/геометрические регрессии; 3D остаётся отключённым до интеграции.

## 0.1.1 — 2026-10-23

- Исправлено падение Android Activity при запуске: назначена тема Theme.AppCompat.Light.NoActionBar.
- Android versionCode увеличен для обновления поверх 0.1.0.
- Добавлена проверка установки и трёх запусков настоящего APK в эмуляторе с logcat и screenshots.

## 0.1.0 — 2026-10-23

- Начальная функциональная 2D-реализация Avalonia с русским интерфейсом, ReactiveUI/Fody и централизованным DI.
- Реальный автономный OSM-пакет Дрозды — Новинки, SQLite/R-tree, A*, разные профили, измеренная статистика.
- Android startup, сборка APK, отсутствие INTERNET в Release-манифесте.
- Отдельный локальный эксперимент MapLibre с реальным Copernicus DEM; не встроен в приложение.
- xUnit/Headless, тест weaving, GitHub Actions, документация и явные блокеры полной приёмки.
