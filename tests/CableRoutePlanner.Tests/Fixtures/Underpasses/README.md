`victory.json` — ограниченная выборка оригинальных WKB дорог, зданий и других
объектов вокруг площади Победы из закреплённой SQLite v3 Беларуси (SHA-256
`f584e0c9963692b31b0f2b6322dc810641729bbabcc410626faf8ea70b703493`).
Подземные участки и идентификаторы узлов повторно извлечены из закреплённого PBF
`4463a38a3b68819c46fd9f89fc286a8f98afec480aff48d5240222254e45ec01`.
В `Name` сохранён исходный OSM source ID. Никакие препятствия не упрощались.
Подземные кандидаты ограничены компонентой кольца `way/25463811`.

Шесть выходов подтверждены общим OSM node ID с наземной пешеходной линией.
Два внутренних терминальных узла не объявляются выходами. Координаты,
источник и правила воспроизведения — в отчёте `docs/evidence/pr55-network-fix/`.

`proletarskaya.json` — аналогичная ограниченная выборка вокруг реального
пешеходного моста `way/25381163` у станции Пролетарская. Используется для
рендера окружающей карты без расчёта маршрута; исходная WKB моста отдельно
сверяется с закреплённой геометрией в визуальном тесте.
