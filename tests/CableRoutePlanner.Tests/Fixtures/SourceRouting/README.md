# Исходные реальные регрессии поиска

Семь `.json.gz` — небольшие полные извлечения из одного закреплённого OSM-пакета, а не полная карта. Каждый файл сохраняет исходный сценарий, настройки, WKB и OSM IDs без изменения геометрии, границы запроса, источник, контрольные суммы и независимый допустимый путь.

Для четырёх внутренних случаев выбраны все объекты исходной области поиска с дополнительным метром запроса. Для трёх внешних случаев выбраны все объекты естественного 4-километрового расширения с тем же дополнительным метром; использована константа радиуса Земли из production. Извлечения включают также стоимостные и нейтральные слои. Геометрии не обрезаны и не упрощены.

Временная SQLite-база объявляет покрытием только полностью извлечённый прямоугольник. Исходный manifest всей Беларуси хранится как происхождение данных и не используется для заявления о наличии отсутствующих объектов за пределами фрагмента. Планировщик получает только исходные две точки и исходные `RoutingOptions`; свидетель используется исключительно для отдельной проверки ожидаемой проходимости.

Хеши, геометрии свидетелей и исходные параметры находятся в [каталоге](../../../../docs/evidence/routing-recovery/witnesses.json); метод и результаты — в [разборе](../../../../docs/evidence/routing-recovery/report.md).
