# Организация тестов

Тестовая сборка остаётся общей для одного запуска и единого coverage gate.
Исходники сгруппированы по проверяемому слою:

- `Domain` — координаты и доменные правила.
- `Application` — сессия планирования.
- `Infrastructure` — маршрутизация и ограничения местности.
- `Persistence` — SQLite и настройки JSON.
- `ViewModels` — команды, состояние, навигация и запуск.
- `UI` — поведение Avalonia, жесты, разметка и камера карты.
- `Composition` — проверка сборки контейнеров и изоляции core-зависимостей.
- `Support` — общие фикстуры, синтетические данные и headless-ввод.

Общее пространство имён `CableRoutePlanner.Tests` позволяет использовать фикстуры
из разных слоёв без копирования. Сценарий, затрагивающий несколько слоёв,
располагается по основному проверяемому поведению.
