Тестовая версия с полной офлайн-картой OSM Беларуси. Интернет при установке и работе не нужен. Python и .NET отдельно устанавливать не требуется.

- Android: скачайте APK `CableRoutePlanner-0.2.1-Belarus.apk` из этого Release. APK из CI (`CableRoutePlanner-CI-Minsk.apk`) предназначен только для проверки интерфейса и не содержит карту Беларуси. Релизные APK используют один ключ подписи; если Android сообщает о конфликте пакета при переходе с CI-сборки или APK, подписанного другим ключом, сохраните нужные данные и удалите старую версию один раз. Последующие релизы обновляются поверх неё.
- Windows 10 x64: скачать setup.exe и установить. Windows 7 ещё не подтверждена.
- Карта включает всю Беларусь и занимает около 2,6 ГБ после распаковки; APK/установщик существенно больше прежней версии. Для установки на Android оставьте не менее 5 ГБ свободного места. Первая распаковка отображает прогресс.
- Перестановка точек пальцем за ручку ≡, статичные номера слотов, красный × для удаления. Исправлено переключение альтернатив. Запас кабеля по умолчанию 10%.
- При единственном найденном маршруте он называется «Маршрут»; ярлыки профилей показываются только при наличии нескольких геометрически различных вариантов. Трасса через мост повторяет координаты обоих концов геометрии моста OSM.
- 3D пока недоступен. DEM, WorldCover и разрешения на водные переходы не включены. Область одного расчёта ограничена 20 км / 100 000 узлами.

Источник карты: Geofabrik/OpenStreetMap, 22.10.2026, ODbL. Один некорректный лесной объект не преобразован; информация сохранена в манифесте. Результат требует инженерной проверки и согласований.
