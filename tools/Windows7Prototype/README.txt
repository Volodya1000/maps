Комплект для Windows 7 SP1 x64

1. Распакуйте ZIP целиком в доступную для записи папку на ноутбуке.
   Не запускайте EXE непосредственно внутри архива.
2. Если .NET Framework 4.8 отсутствует, запустите
   Prerequisites\ndp48-x86-x64-allos-enu.exe и перезагрузите Windows.
   Установщик включён в комплект; Интернет на ноутбуке не нужен для скачивания .NET.
   Он требует Windows 7 SP1. Если он запрашивает дополнительные обновления ОС,
   сначала установите их; комплект не заменяет обновления Windows.
3. launch-on-laptop.cmd — ручной запуск, перемещение и масштабирование карты.
4. test-on-laptop.cmd — автоматическая проверка запуска и снимки окна.
5. После проверки передайте папку results. При ошибке также передайте
   %TEMP%\maps-win7-prototype-error.log.

Это прототип совместимости Avalonia/Mapsui/SQLite с тестовой точкой Minsk.
В нём нет полной карты Беларуси и расчёта кабельных маршрутов.
Основное приложение использует .NET 8 и не поддерживает Windows 7.
Наличие ZIP и успешная компиляция не доказывают запуск на вашем ноутбуке.
Поддерживается только 64-разрядная Windows 7 SP1.

manifest.json содержит commit и контрольные суммы файлов комплекта.
Установщик .NET проверяется по закреплённому SHA-256 и подписи Microsoft.
