# Планировщик кабельных маршрутов Беларуси

C# / Avalonia / ReactiveUI. **Рабочая реализация 2D и расчёта маршрутов; полное MVP по ТЗ пока не готово.** Нет подтверждения Windows 7 и встроенного 3D. Это ограничения приёмки, а не снятые требования.

Реализованы:
- Настоящая офлайн-карта OSM: полный пакет Беларуси в установщиках, район Дрозды — Новинки в исходниках для CI; SQLite, R-tree, векторное отображение Mapsui. Никаких запросов к тайловым серверам.
- Добавление, перетаскивание, удаление, очистка, перестановка точек и копирование координат. Русский адаптивный интерфейс.
- A* по сетке местности с произвольными конечными точками и последовательными промежуточными точками. До трёх различных трасс по профилям стоимости; одинаковые трассы не дублируются.
- Запрет болот, озёр, зданий; реки только через явно разрешённые переходы. Штрафы за лес, поле и пересечение дорог. Мост из OSM сам по себе не разрешает переход.
- Длина и характеристики вычисляются по полученной геометрии и реальным слоям. При изменении точек маршруты удаляются; запоздавшие результаты не публикуются.
- Отдельные Domain, Application, Infrastructure, ViewModels, UI, Bootstrap, Desktop и Android, отдельный Persistence. DI, ReactiveCommand, RoutingState, типизированный ViewLocator, compiled bindings, ReactiveUI.Fody.
- xUnit, Avalonia.Headless, GitHub Actions, самостоятельный инструмент проверки реального маршрута.

## Скачать автономные установщики

[Версия 0.2.0 с полной картой Беларуси](https://github.com/Volodya1000/maps/releases/tag/v0.2.0-preview): Android APK и Windows 10 x64 setup.exe. Выпуск публикуется workflow только после проверки полного APK в эмуляторе и установки Windows-пакета. [PR №2](https://github.com/Volodya1000/maps/pull/2).

Карта занимает около 2,6 ГБ после распаковки, сжатые данные — около 1,2 ГБ. На Android оставьте не менее 5 ГБ для установки и первого запуска. Интернет, Python и отдельно установленный .NET готовому приложению не нужны. В APK отсутствует разрешение INTERNET. Тестовая подпись CI может отличаться от прежнего APK: если Android отклоняет обновление, удалите старую тестовую версию.

Изменения: перетаскивание координат пальцем за ручку ≡ со статичными номерами слотов, красный × у каждой строки, исправленный выбор трассы, запас кабеля 10%, два раздела «Карта» и «Настройки». [Объяснение архитектуры и данных](docs/android-ux-belarus.md).

## Запуск Desktop

Нужен .NET SDK из `global.json`. Данные небольшого реального района уже включены в репозиторий; интернет нужен для первоначального восстановления NuGet, не для работы приложения.

```sh
dotnet restore CableRoutePlanner.Desktop.slnf --locked-mode
dotnet build CableRoutePlanner.Desktop.slnf --no-restore
dotnet test CableRoutePlanner.Desktop.slnf --no-restore
dotnet run --project src/CableRoutePlanner.Desktop
```

Единое решение — `CableRoutePlanner.sln`, фильтр `CableRoutePlanner.Desktop.slnf` позволяет работать без Android workload. На Linux для графического запуска нужны X11/Wayland и системные библиотеки Avalonia; headless-тесты не требуют дисплея.

Порядок точек меняется за ручку ≡, красный × удаляет свою строку. Панорамирование — перетаскивание свободного места; масштабирование — колесо или `+ / −`; точки ставятся коротким нажатием при включённом «Добавлять точки», маркеры перетаскиваются. На узком экране панель переносится вниз. Перестановка в списке проверяется raw touch-событиями Avalonia.Headless; на телефоне дополнительно проверьте pinch-zoom и взаимодействие с системными жестами.

Пакет данных выбирается переменной `CABLEROUTE_DATA` (каталог с `manifest.json` и `geodata.sqlite`). При отсутствии или повреждении пакета отображается ошибка. Синтетические данные не подставляются.

Самодостаточная Windows-сборка:

```sh
dotnet publish src/CableRoutePlanner.Desktop -c Release -r win-x64 --self-contained true -o artifacts/win-x64
```

Эта команда не доказывает поддержку Windows 7 и не заменяет запуск на Windows 10.

## Android APK

Требуются JDK 17, Android SDK Platform 34 / Build Tools 34.0.0 и workload:

```sh
dotnet workload install android --skip-manifest-update
dotnet publish src/CableRoutePlanner.Android -c Release -p:AndroidSdkDirectory=/path/to/android-sdk -p:JavaSdkDirectory=/path/to/jdk17
```

APK: `src/CableRoutePlanner.Android/bin/Release/net8.0-android/publish/by.cablerouteplanner.app-Signed.apk`. Подпись — тестовый ключ сборки. Проект запрещает `INTERNET` в конечном манифесте. Карта копируется из assets в приватный каталог приложения. Установка: `adb install -r <apk>`. Пользователь подтвердил запуск 0.1.1 на Xiaomi; новую версию проверяет CI и затем устройство пользователя.

## Проверка настоящего расчёта без интерфейса

```sh
dotnet run --project tools/CableRoutePlanner.Verify -- samples/real-geodata-fixtures/minsk artifacts/route.geojson 53.9490,27.5180 53.9500,27.5190
```

Координаты задаются пользователем. Выходной GeoJSON содержит рассчитанную трассу и метрики. Маршруты из этого файла не используются приложением как заготовки.

## Проверки перед коммитом

`uv sync --locked` и `uv run --locked pre-commit install` устанавливают локальные проверки. Hooks и CI используют одни команды форматирования, сборки и тестов; [инструкция разработки](docs/development.md) описывает проверки по платформам. В каждом PR добавляйте отдельный [changelog-фрагмент](changes/README.md), общий CHANGELOG собирается Towncrier при выпуске.

## Исследование 3D

Отдельный [MapLibre-стенд](spikes/MapLibre/README.md) содержит локальные OSM-векторы и настоящие Terrarium-тайлы Copernicus DEM. В Linux Chromium проверены terrain, маркеры, обмен JS-событиями, LineString и отсутствие внешних запросов. Он **не встроен в Avalonia** и не закрывает FR-007. Кнопка-заглушка 3D удалена из интерфейса.

## Ограничения приёмки

- Windows 7: современный runtime не поддерживается поставщиком; испытаний на чистой ОС нет. Требование остаётся обязательным.
- 3D: C# WebView, лицензия выбранного адаптера и Windows/Android GPU не проверены.
- Основной пакет содержит только OSM. DEM есть только в отдельном стенде; ESA WorldCover отсутствует. Уклоны и высотные метрики в основном приложении не рассчитываются.
- Полная карта OSM Беларуси подготавливается потоковым чтением PBF, с пространственными индексами и уровнями детализации. Манифест и проверка всех областных центров находятся в docs/evidence. Один некорректный лесной объект не преобразован; полнота препятствий OSM не гарантируется.
- Расчёт ограничен областью 20 км, 100 000 узлов и 100 точками. Сетка может не обнаружить слишком узкий допустимый коридор; уменьшите ячейку. Недостающие препятствия OSM остаются неизвестными.
- Возвращается от одного до трёх разных маршрутов, без обещания трёх независимых коридоров. Целевая функция — инженерная эвристика, не смета.
