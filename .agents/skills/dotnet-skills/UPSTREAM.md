# Vendored .NET skills

The four skill directories beside this notice are minimal, unmodified copies from
[`dotnet/skills`](https://github.com/dotnet/skills) at commit
`cf03b2d2ee17ad2800763108698d869f5b997774` (2026-10-27).

They make the required workflows available from a fresh checkout in Codex
surfaces that discover repository Agent Skills. Their original auxiliary files
are retained. The upstream MIT license is in `LICENSE`.

On a Codex surface with the Plugins browser, the same upstream workflows can
also be installed through the `dotnet-agent-skills` marketplace as the
`dotnet` and `dotnet-test` plugins. That user-level installation is optional:
the repository copies are the reproducible project baseline.
