Исправлена безопасная установка геоданных: SQLite и SHA-256 проверяются до публикации, обновление сериализовано, ошибки публикации откатываются, повреждённая установленная карта восстанавливается. Независимый аудит подземных переходов учитывает исходную связность, подтверждённые входы и связи с дорогами; отчёт сохраняет семантику выбора перехода C#. Добавлены общие регрессионные фикстуры и диагностика и ограниченный повтор при гонке поиска dotnet CLI в Windows CI; ошибки форматирования остаются блокирующими.
Согласованы с main исследовательские проверки маршрутов: независимый Python-аудит сохраняет исходную топологию подземных переходов вместе с сетевыми проверками и диагностикой; объединены наборы регрессионных фикстур.
При сбое Android startup сохраняется экран ошибки и журнал этапов подготовки карты для диагностики полного пакета; ошибка снимка не перезаписывает исходные артефакты ошибки ADB.
При коротких чтениях Android прогресс распаковки сообщается только при пересечении следующего порога объёма данных, без потока одинаковых обновлений UI и журнала.
Повтор при сбое поиска dotnet CLI сохранён в едином проходе форматирования из main; объединены метрики Android smoke и обновлённая инфраструктура сборки офлайн-пакетов.
Проверка лицензий новых офлайн-пакетов больше не зависит от удалённого установщика старого APK.
