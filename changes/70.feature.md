Ручной режим demo собирает из одного SHA переносимые self-contained ZIP для Windows 7 x86 и Windows 10 x64 и подписанный APK с общей полной картой Беларуси, высотами и лицензиями. Конечные архивы проверяются по байтам данных и всем областным центрам; EXE запускаются из распакованной папки, APK проходит установку и два открытия полной карты. В итогах Actions публикуются прямые ссылки, размеры и SHA-256; выпуск установщиков сохранён отдельным режимом.
