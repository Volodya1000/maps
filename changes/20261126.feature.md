На Desktop и Android можно сохранять полный расчёт маршрута со всеми вариантами, исходными точками и настройками, а затем открывать его из раздела «Сохранённые» без повторного построения. Сохранённые варианты доступны для GPS-прокладки на Android; записи с одинаковыми названиями независимы, удаление требует подтверждения.
