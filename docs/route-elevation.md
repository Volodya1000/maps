# Профиль высот и длина по поверхности

После построения откройте вкладку «Маршрут». Профиль относится к выбранной альтернативе: синим показана высота поверхности, зелёным — продольный уклон. Касание, движение мыши и стрелки выбирают расстояние; Home/End — начало/конец. Курсор отмечает соответствующее место на карте. Вертикальный жест над графиком оставляет прокрутку панели доступной.

В метриках раздельно показаны горизонтальная длина WGS84, оценка по поверхности, добавка рельефа и кабель с запасом. Суммарные подъём/спуск считаются по последовательным высотам, а не по разности концов. Сглаживание уклона предназначено для отображения и не меняет интеграл длины.

## Что именно измеряется

Для каждой пары соседних выборок используется sqrt(d² + Δh²), где d — горизонтальная длина того же участка по WGS84. Длина и добавка сравниваются на одинаковой основе. Запас применяется один раз после оценки поверхности. Прежняя сферическая LengthMetres сохраняется для A*, стоимости, ограничения маршрута и GPS-прогресса; её отличие от WGS84 не выдаётся за влияние рельефа.

Выборки охватывают окончательную геометрию после упрощения и выравнивания переходов, со всеми вершинами. Максимальный интервал — половина заявленного разрешения DEM, не более 30 м. Предел 100 000 выборок ограничивает память: при превышении анализ недоступен и используется подписанная 2D-основа. Уточнение интерполяции не повышает разрешение исходного растра.

Пропуски DEM показаны разрывами. При неполном покрытии нет полного итога по поверхности, подъёма или спуска; расчёт кабеля использует явно указанную 2D-оценку. Для мостов, подвесных кандидатов, разрешённых водных и подземных переходов DEM описывает поверхность местности, а не конструкцию: профиль информационный, основа кабеля остаётся 2D.

Copernicus GLO-30 — цифровая модель поверхности (DSM), включающая растительность и строения, относительно EGM2008. Она не определяет траншею, провисание, петли или фактический грунт под лесом. Полученная длина — предварительная геометрическая оценка; инженерный запас остаётся отдельным параметром.

## Офлайн-пакет

В каталоге OSM-пакета могут находиться elevation.sqlite и elevation.sqlite.sha256. Основное приложение не обращается к сервисам высот. Исходные GeoTIFF скачиваются отдельно при подготовке; полные DEM и TIFF не включаются в Git.

Пример подготовки из [официального AWS GLO-30 2021](https://registry.opendata.aws/copernicus-dem/) (файл N53E027):

~~~powershell
uv sync --locked --project tools/GeodataPreparation
uv run --locked --project tools/GeodataPreparation python tools/GeodataPreparation/prepare_elevation.py --dem artifacts/dem/copernicus-N53E027.tif --output samples/real-geodata-fixtures/minsk/elevation.sqlite --source-version "AWS GLO-30 2021" --bounds 27.48 53.93 27.53 53.96
~~~

--dem принимает несколько файлов. Они должны иметь north-up EPSG:4326 и общую систему высот EGM2008 в метрах. Используйте настоящие файлы выбранной поставки; инструмент не преобразует иной вертикальный датум. Геопривязка и размер пикселей читаются из TIFF; нельзя предполагать квадратную сетку 3600×3600. --bounds ограничивает сохраняемую область по родным пикселям.

SQLite хранит JSON метаданных и блоки 128×128 float32 little-endian. NaN означает NoData, а не нулевую высоту. Читатель интерполирует по родной геопривязке, сохраняет пропуски и ограничивает кеш блоков. Перед каждой непустой выборкой проверяется имеющаяся SHA-256 всего файла, с поддержкой отмены. Проверка потоково создаёт временный неизменяемый SQLite-снимок: хешируются ровно те байты, из которых затем читаются высоты. Это дополнительные O(размер базы) чтение и запись на альтернативу и временное место размером с пакет; на Android используется CacheDir. Снимок удаляется после чтения, отмены или ошибки. Для крупного DEM учитывайте дисковое место и время ввода-вывода. Дата файла не считается доказательством целостности. Метаданные включают версию, CRS, датум, разрешение, affine каждого растра, SHA-256 исходников, attribution и ссылку на лицензию.

Desktop использует файлы из CABLEROUTE_DATA или встроенного каталога Data. Android включает их из GeodataDirectory и устанавливает с проверкой SHA-256 до загрузки моделей; обновление DEM обнаруживается независимо от неизменившегося OSM-манифеста. tools/split_android_map.py сохраняет эту необязательную пару. При последующем APK без DEM удаляется прежняя установленная приложением пара, отмеченная внутренним elevation.bundled.sha256. Самостоятельно подготовленные данные со стандартным SHA-файлом этим маркером не помечаются и сохраняются. Отсутствие DEM допускается; повреждённый присутствующий пакет выдаёт ошибку.

Лёгкая демонстрационная сборка Дрозды — Новинки содержит небольшой DEM около 78 КБ. Полная APK и Windows-пакет Беларуси включают высоты всей страны: 840 тайлов по 0,25°, подготовленных из 60 закреплённых SHA-256 исходников Copernicus GLO-30. Флаг HasTerrain в старом OSM-манифесте не является статусом полноты конкретного высотного профиля.

## Полный пакет Беларуси

~~~powershell
uv run --locked --project tools/GeodataPreparation python tools/GeodataPreparation/prepare_country_elevation.py --output artifacts/belarus --cache artifacts/dem/country
uv run --locked --project tools/GeodataPreparation python tools/GeodataPreparation/prepare_country_elevation.py --output artifacts/belarus --verify-only
~~~

Источники и границы закреплены в [belarus-elevation.lock.json](../tools/GeodataPreparation/belarus-elevation.lock.json). Пакет покрывает прямоугольник OSM-поставки: 23.174801–32.76947° E, 51.234408–56.173846° N. Подготовка выполняется отдельно от приложения, включая CI полной APK; приложение остаётся без INTERNET.

В каталоге elevation/index.json находится источник и непересекающиеся области владения тайлов. Каждый тайл имеет собственные elevation.sqlite и SHA-256. Нативные пиксели сохраняют свою геопривязку; запас пикселей за границами владения позволяет интерполировать на стыках без пропусков. Формат SQLite v2 хранит блоки zlib-float32-le, v1 остаётся читаемым. Читатель ограничивает распаковку размером одного блока и проверяет его полноту. Для расчёта хешируются и копируются во временный снимок только затронутые тайлы, а не вся страна.

Для страны значения округлены до 0,1 м перед сжатием; это записано в metadata и версии источника на графике. Максимальная измеренная ошибка округления с представлением float32 — 0,0500031 м. Пространственный шаг исходного DEM остаётся около 30 м; округление не означает дециметровую точность местности. Небольшие прежние fixtures v1 сохраняют исходные float32 без округления. Подготовленные SQLite всей страны занимают около 612 МБ и остаются вне Git.

Android сначала устанавливает целое проверенное поколение, затем атомарно публикует каталог. Ошибка или отмена не заменяет прежнее поколение. Повторный старт проверяет небольшие файлы идентичности; содержимое каждого используемого тайла проверяется при чтении. Предыдущие поколения сохраняются для уже созданных читателей. Упаковка копирует только каталожные тайлы; проверка готовой APK подтверждает SHA-256 каждого тайла и покрытие страны.

[Проверка координат со скриншота, границ страны и снимки исправленного профиля](evidence/route-elevation/country.md). После установки новой APK постройте маршрут заново: прежние сохранённые расчёты сохраняют свои исходные высоты и метрики.

## Сохранённые расчёты

«Сохранить маршрут» сохраняет профиль каждой альтернативы вместе с исходными параметрами расчёта. Открытие из «Сохранённых» восстанавливает прежние высоты, уклоны, источник и оценку кабеля без повторного чтения DEM или A*. Изменившиеся текущие настройки не меняют сохранённые числа.

Новые записи saved-routes.json используют версию 2. Полнота, исходные выборки, статистика, применимость и метрики проверяются совместно: повреждённая запись не заменяет текущий маршрут и не перезаписывает файл. Старые записи версии 1 читаются с исходной 2D-основой; одно чтение не переписывает их. Добавление или удаление записи записывает файл v2. Старое приложение с поддержкой только v1 отклонит новый формат, чтобы не потерять поправку рельефа молча.
