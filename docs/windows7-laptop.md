# Проверка на ноутбуке Windows 7

Скачайте artifact `CableRoutePlanner-Win7-x64-USB-<commit>.zip` для 64-разрядной
Windows или `CableRoutePlanner-Win7-x86-USB-<commit>.zip` для 32-разрядной
Windows из Windows 7 compatibility workflow данного PR и распакуйте целиком в
доступный для записи каталог. x86-комплект также можно использовать на x64.
Оба варианта рассчитаны на Windows 7 SP1 с установленным .NET Framework 4.8.

Для ручной проверки запустите `Windows7Prototype/Windows7Prototype.exe`. Должно появиться окно с картой Mapsui и тестовой точкой Minsk, прочитанной из SQLite. Проверьте перемещение и изменение масштаба.

Для автоматической проверки запустите `test-on-laptop.cmd`. Результаты и снимки окна будут записаны в каталог `results` рядом со скриптом. После окончания отправьте этот каталог разработчику. Если приложение не открылось, дополнительно приложите `%TEMP%/maps-win7-prototype-error.log`.

Это прототип совместимости Avalonia/Mapsui/SQLite, а не полное приложение с маршрутизацией и картой Беларуси. Основное приложение пока собирается для .NET 8, который Windows 7 не поддерживает. Успешная проверка прототипа нужна до выбора отдельного совместимого runtime и переноса основных библиотек; компиляция прототипа сама по себе не подтверждает запуск на Windows 7.

## Переносимый комплект с зависимостями

По метке `ci:windows7` публикуются два отдельных комплекта:
`CableRoutePlanner-Win7-x64-USB-<commit>.zip` и
`CableRoutePlanner-Win7-x86-USB-<commit>.zip`. Скопируйте и распакуйте только
подходящий комплект целиком.
Внутри есть `README.txt`, `launch-on-laptop.cmd`, `test-on-laptop.cmd`, manifest
с контрольными суммами и каталог `Prerequisites` с офлайн-установщиком .NET 4.8.
CI проверяет закреплённый SHA-256 установщика и подпись Microsoft. Скрипт запуска
проверяет архитектуру комплекта и установленный Framework; он не устанавливает
зависимости сам.

Запустите установщик при необходимости, перезагрузите ноутбук, затем выполните
ручную и автоматическую проверки. Windows 7 должна иметь SP1; комплект не
заменяет системные обновления, которые может запросить установщик. Автоматическая
проверка пишет снимки и диагностику в `results`. Основное приложение с расчётом
маршрутов в этот net48-прототип не включено. Если окно сразу закрывается,
запускайте `launch-on-laptop.cmd` или `test-on-laptop.cmd`: они оставляют
консоль открытой, сохраняют `results\preflight.txt` и показывают код ошибки.
Фактическая работа на ноутбуке остаётся непроверенной до получения его
результатов.
