# Матрица требований

**Полная приёмка MVP невозможна в текущем состоянии. Требования не изменены.**

| Требование | Состояние | Подтверждение / открытый объём |
|---|---|---|
| C#, Avalonia, XAML, ReactiveUI, Fody | реализовано и собрано | тест PropertyChanged на production VM |
| MVVM, отдельные слои, DI | реализовано | схема архитектуры, typed ViewLocator, headless |
| FR-001 настоящая офлайн-карта | работает на реальном районе | Mapsui + включённый SQLite; полный пакет Беларуси отсутствует |
| FR-002 точки | реализовано | Application и мышь через Headless |
| FR-003 перенос / устаревание | реализовано | мышь, изменение координат, отмена и поздний результат |
| FR-004 удаление / нумерация | реализовано | автоматические тесты |
| FR-005 clipboard | реализовано | тест абстракции; нативный clipboard требует ОС-проверки |
| FR-006 порядок и несколько точек | реализовано | 2–100, перестановка списка, последовательный маршрут |
| FR-007 настоящее 3D в приложении | **не выполнено** | браузерный MapLibre DEM-стенд подтверждён; C# WebView и все целевые ОС не проверены |
| FR-008 реальные альтернативы и препятствия | реализовано в 2D-пакете | A*, реальные слои, разные профили, запреты; DEM/WorldCover отсутствуют |
| Болотo/озеро/река/лес/поле/дороги | реализовано на доступных OSM-данных | тесты отрезков и переходов; полнота OSM не гарантируется |
| Разрешённые переходы | механизм реализован | реальных согласованных переходов в поставке нет; OSM-мост — только кандидат |
| Windows 10 x64 | сборка получена | запуск, GPU, ввод и чистая установка не подтверждены |
| Windows 7 SP1 x64 | **блокер WIN7-001** | .NET 8 не поддерживает; эксперименты на ОС отсутствуют, альтернативный адаптер не реализован |
| Android startup / APK | сборка получена | Release APK с тестовой подписью; устройство, жесты, поворот и установка ещё не проверены |
| Настройки / об ошибках / адаптивность | реализовано | compiled XAML, сохранение, ошибка пакета, перенос панели вниз; выдвижная нижняя панель не реализована |
| Полная Беларусь | **не выполнено** | есть spatial query; нет полного пакета и потокового препроцессора |
| Автономность | подтверждено в ограниченной среде | runtime-трасса Verify/тестов Linux и браузерный аудит; Windows/Android сетевой аудит ещё требуется |
| xUnit / Headless / GitHub Actions | тесты проходят локально, workflow написан | удалённый CI не запущен из-за GitHub 403 на запись |
| Полная воспроизводимость на целевых ОС | процедура подготовлена, **не подтверждена** | требуются журналы реальных Windows 7/10 и Android |

Синтетические тестовые геометрии существуют только в tests/TestData.cs и явно помечены. Приложение не загружает их и не использует заранее подготовленные маршруты. JS-стенд получает тестовый LineString исключительно для проверки механизма обмена, он не объявляется результатом инженерного расчёта.
