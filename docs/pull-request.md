# Текущее состояние приложения

Приложение позволяет предварительно планировать кабельную трассу по офлайн-геоданным. Пользователь задаёт последовательность точек, получает одну или несколько отличающихся геометрий с метриками длины, леса, поля, дорог и потенциальных водных переходов. Это инструмент предварительного сравнения вариантов, не проект инженерного обследования или разрешение на строительство.

## Офлайн-карта Беларуси

Полный пакет Беларуси размером около 2,6 ГБ после установки уже собран и проверен. Выпущенный Android APK содержит его; для разработки на Desktop пакет можно скачать и проверить командой из [`full-belarus-development.md`](full-belarus-development.md). Текущий Desktop запуск использует явно выбранный каталог данных через `CABLEROUTE_DATA`; тестовый пакет Минска оставлен для быстрых локальных проверок.

## Windows 7

Решение по минимизации дублирования UI описано в [`windows7-decision.md`](windows7-decision.md): первым прототипировать Avalonia 11 с совместимыми общими сборками и тонким .NET Framework 4.8 host. Это ещё не готовый Windows 7 порт. Он требует адаптации части .NET API и проверки Avalonia/Mapsui, SQLite и нативного рендеринга на чистой Windows 7 SP1 VM. .NET 8 текущей сборки Windows 7 не поддерживает.

## Незакрытые инженерные задачи

3D-визуализация и DEM пока не включены в основной расчёт. Оценка маршрута не учитывает рельеф, подземные коммуникации, грунт, доступ на частную территорию и подтверждённые разрешения на каждый мост. OSM мосты показываются только как потенциальные места перехода, которые требуют проверки. Полнота препятствий и полевых данных OSM не гарантируется. Матрица готовности и оставшиеся критерии — в [`acceptance.md`](acceptance.md).
