# Метки PR и дополнительные сборки

Обязательные quality, desktop tests, geodata и Android smoke не отключаются метками.

| Метка | Эффект |
| --- | --- |
| `ci:full-maps` | Явно включить Minsk и Belarus APK; это также поведение PR по умолчанию. |
| `ci:skip-full-maps` | Только проверенный Minsk APK; не тратить время на упаковку страны. `ci:full-maps` имеет приоритет. |
| `ci:windows7` | Собрать переносимый net48-прототип для ноутбука. |
| `test-win7-feasibility` | Дополнительно проверить KVM и ISO; прежняя метка сохранена. |
| `area:routing` | Поиск и проверка маршрутов. |
| `area:map-ui` | Отображение карты и взаимодействие. |
| `area:geodata` | Импорт и подготовка данных. |
| `type:refactor` | Изменение структуры кода. |

В режиме двух карт основной Android job передаёт проверенный Minsk APK во
внутренний artifact подготовки, но не публикует третью прямую APK-ссылку.
Два скачиваемых APK публикуются единственным job: Minsk и Belarus.
Внутренний ZIP с входными файлами сборки не является дополнительной версией APK.
Метки не подтверждают запуск Windows 7: это требует результата с реального ПК.

`ci:routing-benchmark` запускает холодные измерения реальных маршрутов на полной
карте страны и сохраняет отдельный отчёт. Эта метка включает полную карту даже
при наличии `ci:skip-full-maps`; измерения не выполняются на телефоне.
