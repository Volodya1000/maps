пары не перебирались; сам маршрут использует два соседних подземных участка.

Переданы только эти две точки: [false](scenario-false.json), [true](scenario-true.json).

## Данные, выполнение и аудит

Использована готовая SQLite **v3**, 444 `PedestrianUnderpassCandidate`, из артефакта
`pull-request-belarus-data` run [43485336517](https://github.com/Volodya1000/maps/actions/runs/43485336517).
SHA-256 базы: `f584e0c9963692b31b0f2b6322dc810641729bbabcc410626faf8ea70b703493`.
Беларусь заново не конвертировалась. Данные и крупные бинарные файлы не коммитятся.

Реальная маршрутизация: [43570644573](https://github.com/Volodya1000/maps/actions/runs/43570644573),
commit `ece7047bbfbfdc44451b36e54cef8e991a409f85`, существующий Verify `--crossing`.
Verify DLL SHA-256: `4650386c91678222c41fc565928e1c28269211714f67230d168ad30154a6f77b`.
После успешной пары выполнены 176 запусков для 88 замороженных сценариев.
Каждый запуск — отдельный процесс с таймаутом 120 с и лимитом managed heap 1536 MiB.

Усиленный аудит: [43572204548](https://github.com/Volodya1000/maps/actions/runs/43572204548),
commit `7da6962cde91e831eb4f8f3d46fde02d39b93298`. Сохранённые результаты повторно
проверены по той же SQLite; маршрутизация не повторялась. После скачивания
проверено совпадение исходных альтернатив, статусов и времён всех **178** результатов.
SHA-256 обоих архивов, версии и полный разбор находятся в [results.json](results.json).

Аудитор использует Shapely и WKB из SQLite, запрашивая объекты по **фактическому**
контуру каждого маршрута. Для подземного контакта обязательны точная связь из
`underpass_roads`, пересечение оси дороги и покрытие локального участка маршрута
коридором 1 м внутри дорожного окна ±3 м. Участок прослеживается по порядку движения
через вершины до выхода из окна; самопересечение не обрывает его и не склеивает
разные посещения. Проверены покрытие пакета, конечные точки, все дорожные контакты,
здания, болота и вода с существующими правилами допустимых водных переходов.

| Подземный участок / feature ID | Связанная дорога / feature ID |
| --- | --- |
| `way/24422904` / `4606095` | `way/789027454` / `2868696` |
| `way/80427924` / `4606360` | `way/80427934` / `193126` |

Оба контакта разрешены именно подземными участками: `bridgeIds=[]`, `gasIds=[]`.
Аудит **этой же построенной геометрии** с выключенным флагом даёт `violation`
на обеих дорогах: [отрицательная проверка](flag-off-route-audit.json).
18 целевых тестов включают чужую/отсутствующую связь, смещение, неверное направление,
касание, другую дорогу, здания/болота/реки/озёра, повороты и самопересечения.

## Проверки и границы вывода

Локальные `tools/check.py lint`, `data` и `desktop` прошли: 69 Python-тестов
геоданных, 610 .NET-тестов, coverage 95,5% строк / 86,9% ветвей; hooks не обходились.
Обязательный CI проверяется на финальном head PR; Windows/Android не выводятся из
локальной Linux-сборки. Штатная метка `ci:skip-full-maps` исключает повторный country
APK, сохраняя обязательные jobs. Сборка APK не является доказательством маршрутизации.

Маршрут содержит самопересечение, видимое в SVG; оптимальность пути не доказана.
Аудит подтверждает геометрическую допустимость по модели, а не инженерное
согласование кабельных работ. NoRoute относится к заданной области поиска и
параметрам. Алгоритм маршрутизатора и Domain в этой работе не менялись.
