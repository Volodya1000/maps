# Импорт подземного перехода (этап 1)

Из закреплённого PBF извлечены два исходных way с исходными координатами и тегами. Малый extract обработан существующим prepare_country.py. Таблица underpass_roads содержит одну связь: way/24422904 → way/789027454. Числовые ID и SHA исходного PBF сохранены в import.json. Полная Беларусь не пересобиралась.

Формат v3 добавляет таблицу underpass_roads(candidate_id, road_id, tunnel_osm_id, road_osm_id). Составной первичный ключ допускает несколько дорог на один тоннель. Схемы v1/v2 читаются без таблицы. MapFeature передаёт UnderpassRoadIds; ApprovalId остаётся полем инженерного согласования. Новый тип пассивен: разрешения и порталы отсутствуют.

Второй этап: выключенный по умолчанию экспериментальный флаг, узкое Domain-разрешение, портал по геометрии прохода, независимый аудит и реальный сценарий до/после. OSM-кандидат не означает инженерного согласования прокладки кабеля.
