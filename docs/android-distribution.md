# Android APK: тестовая сборка и релиз

В обычном CI артефакт `android-ci-smoke-apk` содержит файл `CableRoutePlanner-CI-Minsk.apk`. Это небольшая тестовая сборка для проверки запуска приложения и UI. В ней только тестовый участок карты Минска; она не предназначена для получения всей Беларуси.

Полный набор OSM находится в APK из GitHub Releases (`CableRoutePlanner-0.2.1-Belarus.apk`). После сжатия он всё ещё занимает около 1,2 ГБ, а после первого запуска требует порядка 2,6 ГБ свободного места для распаковки. Первую загрузку карты приложение показывает с прогрессом.

Android разрешает обновить установленный APK поверх старого только при совпадении `ApplicationId` и сертификата подписи. CI и full-Belarus release используют один preview-ключ: он берётся из секрета `ANDROID_TEST_KEYSTORE` или кэшируется workflow. Если на телефоне стоит APK, подписанный другим временным/локальным ключом, Android выдаёт «конфликтует с другим пакетом». Старый APK нельзя переподписать новым ключом так, чтобы Android принял обновление; для перехода потребуется один раз удалить прежнюю тестовую установку. Удаление приложения очищает его локальные настройки и данные — перед этим сохраните нужные координаты и результаты маршрутов.

После перехода на APK с общим preview-ключом последующие CI/release-сборки сохраняют идентичность подписи и устанавливаются поверх. После merge в `main` дождитесь успешного CI Android job, который сохраняет preview-ключ для `main`. Затем в GitHub Actions вручную запустите `Full Belarus offline installers`, выбрав ветку `main`: workflow соберёт и опубликует полноразмерную версию 0.2.1. Он не запускается от обычной push/PR-сборки, чтобы тестовый APK с картой Минска не выдавался за релиз всей Беларуси.
