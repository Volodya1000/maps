# Android APK: тестовая сборка и релиз

Обычная CI-сборка тестирует `CableRoutePlanner-CI-Minsk.apk` на Android-эмуляторе, но APK не публикуется как скачиваемый артефакт. Диагностический артефакт содержит только журнал smoke-теста. Ранее скачиваемый APK размером около 68 МБ был небольшой тестовой сборкой только с участком карты Минска, не картой всей Беларуси.

Полный набор OSM находится в APK из GitHub Releases (`CableRoutePlanner-0.2.1-Belarus.apk`). После сжатия он всё ещё занимает около 1,2 ГБ, а после первого запуска требует порядка 2,6 ГБ свободного места для распаковки. Первую загрузку карты приложение показывает с прогрессом.

Android разрешает обновить установленный APK поверх старого только при совпадении `ApplicationId` и сертификата подписи, а код версии обновления должен быть не ниже установленного. CI и full-Belarus release используют один preview-ключ: он берётся из секрета `ANDROID_TEST_KEYSTORE` или кэшируется workflow. APK, подписанный другим временным/локальным ключом, нельзя переподписать новым ключом так, чтобы Android принял обновление; такую установку потребуется удалить один раз. Удаление приложения очищает его локальные настройки и данные — перед этим сохраните нужные координаты и результаты маршрутов. Если установка после удаления тоже завершается ошибкой, это уже не конфликт обновления: сохраните точный текст из системного установщика либо вывод `adb install -r <файл.apk>` для диагностики несовместимости пакета/устройства.

После merge изменений в `main` дождитесь успешного CI Android job, который сохраняет preview-ключ для `main`. Затем в GitHub Actions вручную запустите `Full Belarus offline installers`, выбрав ветку `main`: workflow соберёт и опубликует полноразмерную версию 0.2.1. Он не запускается от обычной push/PR-сборки, чтобы тестовый APK с картой Минска не выдавался за релиз всей Беларуси. Для предупреждений Actions используйте раздел «Annotations»: устаревшие Node/Java runtime предупреждения не означают ошибку сборки, но action версии в workflow обновляются вместе с Dependabot.

Релиз 0.2.1 содержит оба APK: `-Minsk.apk` для быстрой проверки и `-Belarus.apk` с полной страной. Они имеют одинаковый package ID и ключ: установка одного заменяет другой. Данные карты выбираются по манифесту. Полная карта разбита на независимые gzip-ресурсы по 64 МиБ исходных данных, затем потоково восстанавливается при первом запуске. Это устраняет единичный ресурс размером более 1 ГБ, но не доказывает причину отказа установщика конкретного телефона. Исходный опубликованный APK проходит apksigner v1/v2/v3; окончательная проверка исправления нужна на том же устройстве.
