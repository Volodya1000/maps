# Отдельные будущие задачи

Эти задачи не входят в исправления настроек и интерфейса карты. Текущий интерфейс работает в 2D; кнопки-заглушки 3D нет.

## Профиль высот маршрута

Сначала добавить практический анализ рельефа без полноценного 3D-движка:

- Выбрать источник DEM, разрешение, лицензию и способ автономной поставки данных.
- Выделить контракт получения высоты с явным отсутствием данных; не подменять пропуски нулевой высотой.
- Строить профиль расстояние–высота вдоль геометрии выбранного маршрута, показывать подъёмы, спуски и уклоны.
- Оценивать длину по рельефу отдельно от плановой длины и применять запас кабеля к выбранному способу оценки.
- Обновлять профиль при выборе альтернативы, удалять устаревший профиль после изменения точек.
- Проверить расчёты на синтетическом склоне, плоском участке и DEM с пропусками; проверить автономный режим.

DEM описывает приближённую поверхность земли. Он не определяет глубину траншеи, подземные коммуникации или пригодность грунта.

## Трёхмерная визуализация

После профиля высот проверить существующий эксперимент `spikes/MapLibre`, механизм рендеринга на Android и Desktop, потребление памяти и работу без сети. Добавлять элемент управления 3D только вместе с рабочим просмотром и обработкой отсутствующих данных. Анализ прямой видимости для радиосвязи требует отдельного расчёта.

## Совместимая сборка Windows 7

Сохранить общие модели, алгоритмы, контракты и по возможности UI. В [актуальном исследовании](windows7-decision.md) первым кандидатом выбран общий Avalonia 11 UI с небольшим legacy host на .NET Framework 4.8. Отдельный WPF-проект — резерв, если нативный стек не работает на Win7 SP1. Современный WPF на .NET 8/10 не обеспечивает поддержку Windows 7.

Перед реализацией:

- Проверить возможность совместимых целей общих библиотек, например `netstandard2.0`; проверить используемые современные API и поддержку records.
- Проверить зависимости карт, графики, SQLite и ReactiveUI на Windows 7 SP1/.NET Framework 4.8.
- При необходимости выделить платформенные адаптеры хранения, карты, буфера обмена и получения данных.
- Подтвердить установку и автономное построение маршрута на целевой Windows 7, документировать точные версии зависимостей и ограничения окружения.

Поддержка Windows 7 не считается реализованной до проверки приложения и всех нативных зависимостей на целевой системе. Полную переработку приложения ради этой платформы не планировать.
