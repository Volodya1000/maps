# Изменения 0.2.0

## Интерфейс

Номера слотов находятся слева от карточек координат. Перетаскивание за ручку ≡ работает мышью и касанием; при переносе двигается карточка, а номера остаются на своих местах. У края списка включается прокрутка. Красный × удаляет именно свою строку. Изменение порядка или удаление сбрасывает рассчитанные маршруты.

Каждая альтернатива выбирается командой по идентификатору. Карта показывает выбранную геометрию, панель — её характеристики. Трассы, совпадающие по большей части в пределах размера ячейки, не выдаются за отдельные варианты. Число вариантов зависит от местности: три результата не гарантируются.

Запас кабеля по умолчанию — 10%. Ранее сохранённые пользователем настройки сохраняются. Удалены страница «О данных» и подзаголовок «Предварительное планирование». Атрибуция OSM остаётся на карте. Не реализованная кнопка 3D отключена с пояснением; полноценный 3D остаётся открытым требованием.

## SQLite и Persistence

SQLite хранит векторную геометрию OSM, исходные идентификаторы и пространственные индексы R-tree. Это позволяет читать только видимую область и препятствия возле расчёта. Для всей страны загрузка всех объектов в оперативную память неприемлема. Уровни детализации отображения хранятся отдельно: маршрутизация использует исходную геометрию препятствий.

`CableRoutePlanner.Persistence` — отдельный проект. Он реализует `IGeodataRepository` и `ISettingsStore` из Application. Infrastructure содержит маршрутизацию и геометрические операции. Bootstrap регистрирует реализации. EF Core сейчас не добавлен: изменений бизнес-сущностей в БД нет, запросы преимущественно пространственные, а ORM не заменяет R-tree. При появлении проектов пользователя и истории расчётов его можно добавить в Persistence.

## Python и автономная установка

Python, osmium и Shapely используются только для подготовки распространяемой карты из исходного OSM PBF. Приложение на C# не запускает Python и не требует его установки. Зависимости подготовки фиксируются `pyproject.toml` и `uv.lock`; `requirements.txt` удалён.

```sh
uv sync --project tools/GeodataPreparation --locked
uv run --project tools/GeodataPreparation --locked python tools/GeodataPreparation/prepare_country.py \
  --pbf /data/belarus.osm.pbf --expected-md5 <MD5-из-Geofabrik> --output /data/belarus-package --compress
```

Полный пакет передаётся сборке через `-p:GeodataDirectory=/absolute/path/belarus-package`. Он включается в Android assets или в каталог Data Windows-поставки. APK устанавливается локально без сети; первая распаковка карты выполняется с индикатором прогресса. Приложение не имеет разрешения INTERNET. Сборка из исходников требует первоначальной загрузки SDK/NuGet; готовое приложение — нет.

Небольшой реальный район Минска остаётся в репозитории для быстрых CI-проверок. Полный пакет не добавляется в историю исходников. Его манифест содержит контрольные суммы, дату источника, количества объектов и ошибки преобразования. OSM не гарантирует полноту препятствий. DEM, ESA WorldCover и разрешения на переходы в этот пакет не добавляются искусственно. Ограничение текущего расчёта — область до 20 км и 100 000 узлов; наличие карты всей страны это ограничение не снимает.
