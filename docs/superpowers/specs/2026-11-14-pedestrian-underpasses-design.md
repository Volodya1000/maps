# Подземные переходы по умолчанию — дизайн

## Цель

Сделать проверенные OSM-кандидаты пешеходных подземных переходов доступными
пользовательскому приложению по умолчанию, не меняя правила допуска дорожных
контактов, и явно сообщать об их инженерной непроверенности.

## Границы

- `RoutingOptions.AllowExperimentalPedestrianUnderpasses` остаётся внутренним
  переключателем для Verify и тестов; значение `false` продолжает отключать
  переходы в этих путях.
- `JsonSettingsStore` нормализует это значение в `true` при чтении и записи,
  как существующее обязательное предпочтение газовых переходов. Старые JSON и
  SQLite v1/v2 остаются читаемыми.
- Результат маршрута несёт отсортированные идентификаторы фактически
  использованных кандидатов. Близость линии перехода не является доказательством
  использования.
- На Mapsui переходы показываются только на детальном LOD: светлая обводка,
  фиолетовый пунктир, символ тоннеля и подпись «Подземный переход» на самом
  подробном уровне. Обзорные LOD их не загружают.
- Маршрут с использованным переходом получает точное предупреждение:
  «Подземный переход. Прокладка кабеля требует инженерной проверки».

## Подходы

1. Удалить опцию из `RoutingOptions`: исключает ложное выключение, но лишает
   Verify и внутренних тестов независимого сравнения. Отклонён.
2. Нормализовать только в UI: Verify сохранится, но старый JSON может дойти до
   пользовательского маршрута через другой composition root. Отклонён.
3. Нормализовать на границе пользовательских настроек, а факт использования
   собирать из той же пространственной проверки, которая разрешает дорожный
   контакт. Выбран: единая политика с газовыми переходами, без дублирования и
   без новых правил допуска.

## Архитектура

Infrastructure расширяет `EdgeEvaluation` идентификаторами подземных
кандидатов и `RouteAlternativeBuilder` объединяет их для итогового
`RouteAlternative`. Domain остаётся BCL-only. ViewModels форматируют готовый
результат; UI только передаёт его в Mapsui. Persistence по-прежнему выбирает
оригинальные объекты при `metresPerPixel <= 10`, а стиль скрывает кандидаты при
более грубом масштабе — это сохраняет растровый LOD и не требует GPS.

## Не-цели

Не добавляются UI-переключатели, не меняются A*, стоимость, правила дорожных
контактов и визуализация газовых переходов. OSM-кандидат не объявляется
инженерно согласованным сооружением.
