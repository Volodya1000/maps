# Геоданные и воспроизводимость

## Основной пакет

`samples/real-geodata-fixtures/minsk`: реальные данные района Дрозды — Новинки, Минск; bounds `[27.48, 53.93, 27.53, 53.96]`, EPSG:4326. Получены из официального OSM API 2026-10-23. Включены 1003 здания, 903 дорожных объекта, 98 лесных объектов, 35 полей, 33 водотока, 14 озёр/водоёмов, 35 мостов-кандидатов и один болотный объект. Эти числа — состав снимка, а не показатели маршрута.

OSM: https://www.openstreetmap.org/copyright, ODbL 1.0 / DbCL 1.0. Полные тексты и NOTICE включены в пакет. Исходник сжат без случайного gzip timestamp; SHA-256 исходника и базы — в manifest.json, дополнительные relation/full URL — в source.osm.sources.json. API не публикует отдельную контрольную сумму bbox-ответа: мы фиксируем SHA-256 после HTTPS-загрузки и проверяем её при повторной сборке; это не независимая подпись поставщика.

```sh
uv sync --project tools/GeodataPreparation --locked
uv run --project tools/GeodataPreparation --locked python tools/GeodataPreparation/download_snapshot.py --bounds 27.48 53.93 27.53 53.96 --output /tmp/minsk.osm.gz
```

Повторная сборка включённого снимка без сети:

```sh
uv run --project tools/GeodataPreparation --locked python tools/GeodataPreparation/rebuild_sample.py --output artifacts/rebuilt-minsk
```

Сборщик объединяет multipolygon outer/inner, нормализует/обрезает геометрию через GEOS, создаёт WKB и SQLite R-tree. Неполные relation или незамкнутые площадные препятствия приводят к ошибке; они не отбрасываются тихо. Водотокам-линейным объектам присваивается tagged width или консервативная ширина 12 м, минимум 6 м. Это явно указанное допущение для неизвестной ширины, не результат измерения. Класс воды определяется OSM-тегами. Наличие мостов не означает наличие разрешённых переходов.

`prepare.py --crossings reviewed.geojson` принимает **подготовленные инженером** Polygon/MultiPolygon с `properties.approval_id`. В поставке таких разрешений нет. Тесты используют только явно помеченные синтетические разрешения, не применяемые к реальным данным.

Манифест фиксирует состав пакета, bounds, хеш базы, источники, лицензии, наличие terrain/worldcover и ограничения. SQLite открыт только для чтения. Приложение читает пространственное окно; все данные страны в память не загружаются. Подготовка полного пакета всё ещё отсутствует: нынешний XML-сборщик загружает небольшой исходник в память, не предназначен для PBF всей страны.

## Полная Беларусь — не подготовлена

Планируемый первичный источник: https://download.geofabrik.de/europe/belarus.html. Нужны потоковый PBF-import, согласование OSM/WorldCover/DEM, уровни детализации и офлайн-тайлы, разбиение DEM, контролируемый объём данных и проверка покрытия. До выполнения этого этапа нельзя заявлять поддержку всей Беларуси. Вне bounds отображается отсутствие данных, а расчёт отклоняется.

## Copernicus DEM — отдельный 3D-стенд

22 настоящих Terrarium-тайла в `spikes/MapLibre/terrain` получены из GLO-30 COG N53E027 и N54E027. Исходные URL, SHA-256 файлов и тайлов записаны в отдельном манифесте. Преобразование выполняет `prepare_terrain.py`: bilinear reprojection EPSG:3857, RGB Terrarium, 1/256 м кодирования (не точности съёмки). Отсутствующие данные вызывают ошибку.

GLO-30 представляет DSM, включая растительность и строения. Условия и обязательные уведомления — в `spikes/MapLibre/NOTICE.txt`; [первичный источник](https://dataspace.copernicus.eu/explore-data/data-collections/copernicus-contributing-missions/collections-description/COP-DEM), [поставка AWS](https://registry.opendata.aws/copernicus-dem/). Эти тайлы пока не подключены к основному приложению и не используются для высотной статистики маршрутов.

## ESA WorldCover — не подключён

Официальный источник: https://esa-worldcover.org/. Нужны импорт классификации, контроль версии и лицензии выбранной поставки, правила приоритетов при конфликте OSM/WorldCover и тесты с реальными растрами. Нельзя считать отсутствие объекта OSM доказательством отсутствия препятствия.

## Полный набор Беларуси (0.2.0)

Источник: фиксированный Geofabrik `belarus-261022.osm.pbf`, MD5 `a2327228173b7fe8e74e2097e3dae0d4`, SHA256 и время снимка — в `docs/evidence/belarus-manifest.json`. Подготовка: `prepare_country.py --compress`. Потоковый osmium восстанавливает площадные multipolygon, внутренние кольца и линейные объекты; оригинальная геометрия хранится отдельно от трёх уровней детализации. Ошибки преобразования записываются в манифест; в этом снимке один лесной объект не преобразован. Неизвестная информация о высотах и разрешениях не подставляется.

Масштабное приближение для буфера линейной реки использует средний радиус Земли IUGG. Если width отсутствует, применяется консервативная техническая ширина 12 м, минимум 6 м; для просеки — буфер 4 м. Это допущения подготовки, а не измеренные ширины или разрешения на строительство. Они унаследованы от небольшого пакета; уточнение инженерными данными остаётся необходимым.

APK содержит сжатую базу, манифест и лицензии; Windows setup содержит самодостаточное приложение и исходную SQLite-базу. Карта не требует сети и не загружается после установки. SQLite/R-tree читает выбранную область; вся страна не материализуется в RAM.
