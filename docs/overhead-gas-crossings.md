# Воздушные газопроводы над дорогами

## Проверка данных, 28 октября 2026

Проверен живой Overpass API (`https://overpass-api.de/api/interpreter`):

```overpass
[out:json][timeout:60];
area["ISO3166-1"="BY"][admin_level=2]->.by;
way(area.by)["man_made"="pipeline"]["substance"="gas"]["location"="overhead"]->.p;
(.p;way(around.p:30)["highway"];);out geom;
```

Ответ: 67 линий газопроводов, 70 соседних линий highway. Проверка пересечений
полных геометрий дала 13 пар pipeline–highway с точечным пересечением.
Одна пара относится к highway=path, остальные 12 — service, unclassified, track.
Это число пар объектов, а не оценка полноты покрытия страны.
Современный ответ Overpass может отличаться от закреплённого PBF приложения.

Примеры кандидатов (OSM way ID, координаты lon/lat):

| Газопровод | Дорога | Место |
| --- | --- | --- |
| 544350743 | 544350741 (service) | 30.1415330, 55.2013179 |
| 670219527 | 1093824720 (unclassified) | 27.5724298, 52.8563829 |
| 670219534 | 25270924 (unclassified) | 27.5814935, 52.8576786 |
| 1313039624 | 771578601 (track) | 27.4662492, 52.8259911 |

`overhead` выбирается строго; `overground` и `underground` не являются
эквивалентом воздушного перехода над проезжей частью. Неточное или отсутствующее
тегирование означает, что часть существующих переходов не будет обнаружена.

## Инженерный смысл

Это кандидаты для осмотра. OSM не подтверждает высоту, несущую способность,
совместимость крепления кабеля с газопроводом, доступность опор, согласие
владельца или разрешение на работы. Отметка не делает переход согласованным,
не открывает водные препятствия и не является обещанием безопасности.

## Реализация

Подготовка сохраняет исходный `OverheadGasPipeline` и короткий производный
`GasPipelineCrossingCandidate` только в месте поперечного пересечения с Road.
Касания концами, совместные линии и пешеходные пути исключены. Производный
участок повторяет ось трубы, по 12 м в обе стороны (в пределах исходной линии),
с вершиной в месте дороги. На подложке виден бирюзовый участок с подписью «ГАЗ»;
весь трубопровод не загромождает карту.

Настройка «Предпочитать воздушные переходы газопроводов» выключена по умолчанию.
После её включения поиск получает дополнительные соединения по оси кандидата.
Штраф наземного пересечения дороги снимается только если маршрут рядом с осью
дороги следует оси трубы с допуском 1 м. Окно проверки ±3 м от оси дороги —
алгоритмическое допущение, не измеренная ширина проезжей части. Длина и штрафы
лесов/полей сохраняются. Кратчайший профиль может предпочесть наземный путь;
другие профили сравнивают стоимость обхода через кандидата.

Кандидат не снимает запрет воды, болот и зданий. В метриках он учитывается
отдельно и не становится согласованным переходом. Порталы вне загруженной
области не используются: там могли остаться незагруженные препятствия.
Предпочтение кандидата — инструмент предварительного поиска для проверки,
а не разрешение прокладывать кабель по действующему газопроводу.

В закреплённом небольшом пакете Минска таких объектов нет. Для проверки нужны
полный пакет Беларуси с новой подготовкой либо синтетические регрессионные
сценарии. Добавление импортера не дополняет OSM отсутствующими газопроводами.
