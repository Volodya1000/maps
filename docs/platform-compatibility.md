# Совместимость и блокеры приёмки

Исследование до основной реализации, 2026-10-23. Статус: **MVP не принят**.
Среда исполнителя: Linux x64, без Windows VM и Android-устройства. Отсутствие тестовой ОС не является доказательством работоспособности или невозможности поддержки.

| Проверка | Windows 10 x64 | Windows 7 SP1 x64 | Android |
|---|---|---|---|
| .NET 8 | целевой runtime, требуется проверка редакции/сборки ОС | NOT_TESTED; основной Desktop остаётся net8.0, блокер WIN7-001 | отдельный startup, требуется workload |
| Avalonia/мышь/клавиатура/GPU | не проверено на устройстве | не проверено | касания/жесты не проверены на устройстве |
| Офлайн-карта Mapsui | win-x64 сборка получена, запуск на ОС не проверен | не проверено | Release APK получен, устройство не проверено |
| Настоящий DEM 3D | не реализован, блокер TERRAIN-001 | не реализован | не реализован |
| Чистая установка | не проверено | не проверено | не проверено |

Первичные источники:
- https://github.com/dotnet/announcements/issues/226 — .NET 7+ не поддерживает Windows 7; поддержка .NET 6 на Win7 завершилась с ESU в январе 2023.
- https://learn.microsoft.com/dotnet/core/install/windows — текущая матрица .NET.
- https://docs.avaloniaui.net/docs/supported-platforms — актуальные уровни поддержки Avalonia; не гарантия для зафиксированной версии 11.3.0.
- https://blogs.windows.com/msedgedev/2022/12/09/microsoft-edge-and-webview2-ending-support-for-windows-7-and-windows-8-8-1/ — WebView2 109 последняя ветка для Windows 7, SDK >=1.0.1519.0 не поддерживает эту ОС.

Решение: общие Domain/Application не содержат UI-зависимостей; основная сборка остаётся .NET 8. В PR #26 VERIFIED KVM и net48 prototype build, но Windows 7 boot/GUI остаются BLOCKED без лицензированного образа. Windows 7 не включена в список подтверждённых платформ.

Обновлённое [исследование Windows 7](windows7-decision.md) выбирает первым кандидатом Avalonia 11 с host на .NET Framework 4.8 и общими XAML/ViewModels. Текущий prototype smoke contract является отдельной экспериментальной проверкой и не закрывает WIN7-001; основной Desktop и production routing остаются NOT_TESTED.

Для каждого эксперимента на целевой ОС сохранить: образ и обновления ОС, CPU/GPU/драйвер, SDK/runtime/WebView версии, SHA коммита, журналы запуска, скриншоты, сетевую трассу при запрете исходящей сети, результаты мыши/клавиатуры/касания/3D и чистой установки. До заполнения этой матрицы полная приёмка невозможна.

## Полученные локальные результаты

.NET SDK 8.0.426, Avalonia 11.3.0, Mapsui 4.1.9. Локальные сборки и поведенческие тесты выполняются общими командами `tools/check.py`; CI отдельно проверяет Ubuntu, Windows Server, Android API 34 и эмулятор. Компиляция подтверждает совместимость пакетов на уровне сборки, не Windows 7/10, GPU, ввод или физическую установку. APK проверяется `aapt`: INTERNET отсутствует.

MapLibre 4.7.1 и 22 реальных Terrarium DEM-тайла проверены только в отдельном Linux Chromium-стенде. Это частичный эксперимент движка, не реализация FR-007 в приложении. Отчёт docs/evidence/maplibre-check.json.

## Android 0.1.1

После отчёта с физического Xiaomi исправлена конкретная ошибка запуска 0.1.0: `You need to use a Theme.AppCompat theme`. Activity получила явную тему с родителем `Theme.AppCompat.Light.NoActionBar`. В CI проверены установка и три запуска исправленной Activity на Android 14/API 34 x86_64; показ карты подтверждён screenshot. Физический Xiaomi, касания и прочие целевые платформы требуют своих проверок.
