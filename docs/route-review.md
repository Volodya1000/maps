# Проверка маршрута на карте

## Контакты с дорогами

Переключатель «Пересечения с дорогами» показывает контакты только выбранной
альтернативы. Круг обозначает точечное пересечение, широкая линия — общий участок
маршрута с геометрией дороги/моста. При выборе другой альтернативы слой заменяется,
при выключении или удалении маршрута — очищается. Данные рассчитываются один раз
по итоговой геометрии, без дополнительных запросов при вращении карты.

Это проверка совпадений с осью дороги (либо импортированным полигоном дороги),
не с полной полосой отвода. Близкие параллельные линии без геометрического
пересечения не считаются общим участком. Ширины проезжей части в текущем пакете
не моделируются. Визуальные контакты и прежняя метрика пересечённых дорог имеют
разный смысл: метрика не считает движение вдоль линейной оси пересечением.

## Почему нарисованный мост может заканчиваться в воде

Внешний вид подложки и допустимость расчётного перехода проверяются отдельно.
OSM-линия с bridge=yes описывает размеченный пролёт, а не автоматически весь
подъезд к нему. В подготовке линейные водотоки буферизуются при отсутствии
ширины; берег также упрощается для отображения. Поэтому концы пролёта могут
оказаться внутри нарисованной воды при корректных исходных координатах, а иногда
в исходных данных действительно недостаёт геометрии. По одному скриншоту без
координат нельзя различить эти случаи.

Приложение не удлиняет такой мост до ближайшей суши и не открывает по нему
произвольный коридор. В расчёте используется исходная геометрия, фиксированный
допуск 2 м и проверка каждого отрезка. Неполный мост может остаться видимым на
подложке, но не должен давать маршрут по воде. Для разбора конкретного объекта
нужны его координаты/OSM ID и тот же офлайн-пакет.

## Что проверять на телефоне

1. Построить маршрут с несколькими альтернативами, включить контакты.
2. Сравнить круги пересечения и выделенные общие участки на каждой альтернативе.
3. Выключить слой, повернуть и масштабировать карту: производительность подложки
   не должна зависеть от слоя, пока он выключен.
4. Проверить переход по извилистому мосту и сохранение выбранной точки после
   перемещения и перестановки точек во время расчёта.

Локальные UI-тесты не измеряют FPS на физическом Android-устройстве.
